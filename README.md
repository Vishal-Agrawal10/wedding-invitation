# Royal Indian Wedding Invitation

A cinematic, mobile-friendly React wedding invitation with an animated welcome, countdown, music, event itinerary, gallery, Google Maps and WhatsApp RSVP.

## Personalise

Edit `app/wedding.config.ts`. Names, date, family copy, events, gallery images, venue, map links, WhatsApp number and music are kept together in that file.

Replace `public/royal-wedding-hero.png` with your own hero photo, and add further images in `public/` before updating the gallery paths in the configuration.

## Preview

```bash
npm install
npm run dev
```

## GitHub Pages

The included GitHub Actions workflow builds and publishes the static site for free. Push the project to a GitHub repository, keep the default `main` branch, then choose **GitHub Actions** as the Pages source in the repository settings.
